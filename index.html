Penjelasan Algoritma

Algoritma Dynamic Programming untuk TSP memakai konsep bitmask.

Rumus utama:

dp[mask][i]

yaitu jarak minimum untuk mengunjungi seluruh kota dalam mask dan berakhir di kota i.

Algoritma mencoba seluruh kemungkinan rute, kemudian menyimpan hasil terbaik agar perhitungan tidak diulang.

Metode ini dikenal sebagai Held-Karp Algorithm

Kompleksitas:

O(n² · 2ⁿ)
